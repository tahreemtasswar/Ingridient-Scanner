\# Ingredient Scanner (QR/Barcode Web App)



A Flask-based web application that scans product barcodes/QR codes and displays real product information using the Open Food Facts API.



\## Features

\- Scan QR codes and barcodes using mobile camera

\- Fetch real-time product data (ingredients, allergens, images)

\- Simple and responsive web interface

\- Works on mobile devices using ngrok for testing



\## Tech Stack

\- Python (Flask)

\- HTML, CSS, JavaScript

\- REST API (Open Food Facts)

\- SQLite (optional storage)

\- ngrok (for public testing)



\## What I learned

\- Full-stack web development

\- API integration

\- Handling real-time data

\- Mobile camera integration in web apps
